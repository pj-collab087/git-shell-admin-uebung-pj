# git-shell-admin-uebung-pj
## Skripte

Im Ordner `scripts` befinden sich folgende Shell-Skripte:

- **systeminfo.sh** – zeigt Benutzername, Hostname, Datum/Uhrzeit und Arbeitsverzeichnis an
- **dateipruefung.sh** – fragt nach einem Dateinamen und prüft, ob dieser existiert
- **projektstruktur.sh** – legt automatisch eine Projektordnerstruktur mit Unterordnern und einer Textdatei an
- **admin-menu.sh** – zeigt ein Terminal-Menü mit mehreren Funktionen zur Auswahl

## Ausführung

Die Skripte werden im Terminal wie folgt gestartet:

```bash
./scripts/systeminfo.sh
./scripts/dateipruefung.sh
./scripts/projektstruktur.sh
./scripts/admin-menu.sh
```

Falls ein Skript nicht ausführbar ist, kann es alternativ mit `bash scripts/DATEINAME.sh` gestartet werden.
